# 일기곰 (Ilgigom)

> 하루 한 줄, 10년의 오늘. 같은 날짜의 10년을 한자리에서 되돌아보는 다이어리.

**일기곰**은 오늘을 기록하면 지난 10년의 '같은 날'을 나란히 볼 수 있는 iOS 다이어리 앱입니다.

## 주요 기능

- **오늘 + 지난 10년**: 한 화면에 오늘과 지난 10년의 같은 날짜가 카드 스택으로 쌓입니다. 탭하면 연혁 타임라인으로 펼쳐집니다.
- **자유 기록**: 글자 수 제한 없는 자유 작성 + 사진 1장 + 기분(곰 표정)
- **해시태그 · 검색**: 해시태그·단어로 지난 일기를 날짜별로 검색
- **위치 · 날씨 · 시간**: 버튼 한 번으로 그 순간의 도시·날씨·시간 기록
- **캘린더**: 월간 그리드에서 기록한 날을 한눈에, 날짜를 눌러 그 해로 이동
- **매일 알림**: 원하는 시간(분 단위)에 리마인더
- **iCloud 내보내기 · 백업**

## 개발/빌드

- iOS 17+ · SwiftUI · SwiftData
- 프로젝트는 [XcodeGen](https://github.com/yonaskolb/XcodeGen)으로 생성합니다.

```bash
xcodegen generate
open Ilgigom.xcodeproj
```
